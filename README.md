# Titanfall 2 x dghub插件

DGHub 外部插件（SDK v1）：Titanfall2多人模式中泰坦血量的**数值变化**映射为郊狼电刺激。

#原理介绍
  这个插件的原理为一条单向数据链：用CE标定泰坦血量变化对应的地址，后续检验确定该地址为固定值，故可用于标定血量。

同时这条链上最先要保证的是读数可信。每一帧都先过一遍硬性检查：读不到、最大血量不合理、血量越界、单帧跳变超过合理范围，这类帧直接丢掉，并不产生输出。

可信的帧才进换算。状态机只看血量本身和它带来的状态变化：血量落到哪个档位就决定持续强度，一次掉血足够明显才折算成一次脉冲，算出的值再按设备上限换算成实际下发强度。强度走 DGHub 暴露的接口，插件自己不直接操作设备，所以暂停、退出、失联时都能把通道归零。


- 强度只负责下发与归零；实际体感请从低档试起，并记住急停手段（急停热键、退出归零、失联 3 秒归零）。
- 面向成年用户自用，请遵守所在地法律法规与设备厂商说明。
